# Plan: Wide Desktop 3-Tier Grid + Content-Aware Layout

## Why

Runaho: "Portfolio alanini genisletelim, cok bosluk var yanlarinda
hizalama olsun ve test edelim secince demo veya kendin geliyormu
planladigimiz alanlar."

Olcum (1280x900 viewport):
- Tek kolon 760px centered, 520px sag-sol bos
- Bu genis ekranda outline outOfScope gibi duruyor
- Demo ve bos state'ler ayni layout ile zayif

## Final Layout

### Tier 1 (<960px) - mobile
- Tek kolon, aside asagi taser
- Mevcut davranis

### Tier 2 (960px-1280px) - tablet/orta desktop
- 2 kolon: [Main 1fr] [Aside 320px]
- Mevcut davranis

### Tier 3 (>1280px) - wide desktop
- 3 kolon: [Main 1fr] [StatsPanel 280px] [Aside 280px]
- Empty state icerigi:
  - Merkez: Empty rich (3 steps + Quick Add formu)
  - Sol yan: "Sector explorer" (hangi sectorde hangi sembol var)
  - Sag yan: Concept guide
- Demo/Kendi state icerigi:
  - Merkez: Portfolio tablosu (genis, daha fazla hisse sigar)
  - Sol yan: Portfolio stats (buying power, maintenance coverage, sector dagilimi, toplam deger)
  - Sag yan: Profile + Cash + Watchlist + Concept

## Implementation

### CSS Grid
- Grid template 3 kolonluk: `grid-template-columns: minmax(0, 1fr) 280px 280px;`
- 1280'de: max-width 1280, sagdan hizali degil center
- 960 altinda: single column auto
- 960-1280 arasi: 2 kolon var

### Component Changes
1. `+page.svelte`: grid layout artik 3 kolon destekliyor
2. Yeni component: `src/lib/components/portfolio/PortfolioStatsPanel.svelte`
   - Sol yan panel - KPI'lar + sector dagilimi (bosken "Sector explorer" placeholder)
3. Mevcut aside compact - sadece profile + watchlist (concept full dagilim)
4. i18n: yeni key'ler (portSectorExplorerTitle, etc.)

### State Logic
- Empty state: Sol panel = "Sector explorer" (sector listesi + en populer semboller)
- Non-empty: Sol panel = Stats (buying power, coverage, etc.)
- Right aside: Empty state'te sadece concept guide, non-empty'de tam

## Files Changed
- src/routes/portfolio/+page.svelte (3-kolon layout)
- src/lib/components/portfolio/PortfolioStatsPanel.svelte (yeni)
- src/app.css veya inline (grid CSS)
- messages/tr.json, messages/en.json (yeni key'ler)
